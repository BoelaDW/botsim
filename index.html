Share your robot
  1. Build it in the Workshop, fill in your name and a description, and press Save .bot file.
  2. Upload it here (needs a free GitHub account). GitHub turns the upload into a pull request; an automatic check loads it, weighs it and runs it in the arena.
  3. Once it's accepted it shows up here for everyone within a few minutes.

Just want to fight a friend? Send them the .bot file: Arena → Load a .bot file. Every gallery robot also has a link that opens the arena with it loaded.
